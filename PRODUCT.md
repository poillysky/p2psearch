# P2P Search

## Product
Self-hosted eD2K / KAD search tool. Users search the network, copy ed2k links, and tune proxy / server / engine settings.

## Audience
Local operators who already know eMule/eD2K vocabulary. Chinese UI.

## Surfaces
- **Search** (`/`): primary task — query, status, results table, copy ed2k.
- **Settings** (`/settings`): edit `config.yaml` via form; some changes need process restart.

## Mode
Operate. Scanability and task speed beat brand theater. Brand still leads the search first viewport.

## Constraints
Vanilla HTML/CSS/JS embedded in Go. No build step, no React, no icon libraries.
